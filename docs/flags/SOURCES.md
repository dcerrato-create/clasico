# Flags kept in this folder

Most flags in the app come from flagcdn.com. The ones here are flags it does
not have: six countries that no longer exist (each shown with the last flag it
used), and Honduras, whose flag on flagcdn.com is the turquoise 2022 version
rather than the deep blue one in use again since 2026.
Each file was downloaded unchanged from Wikimedia Commons, where all are
marked as public domain.

| File | Team in the dataset | Wikimedia Commons file |
|---|---|---|
| yugoslavia.svg | Yugoslavia | [Flag of Yugoslavia (1946-1992).svg](https://commons.wikimedia.org/wiki/File:Flag_of_Yugoslavia_(1946-1992).svg) |
| east-germany.svg | German DR | [Flag of East Germany.svg](https://commons.wikimedia.org/wiki/File:Flag_of_East_Germany.svg) |
| south-vietnam.svg | Vietnam Republic | [Flag of South Vietnam.svg](https://commons.wikimedia.org/wiki/File:Flag_of_South_Vietnam.svg) |
| south-yemen.svg | Yemen DPR | [Flag of South Yemen.svg](https://commons.wikimedia.org/wiki/File:Flag_of_South_Yemen.svg) |
| saarland.svg | Saarland | [Flag of Saar (1947–1956).svg](https://commons.wikimedia.org/wiki/File:Flag_of_Saar_(1947–1956).svg) |
| manchukuo.svg | Manchukuo | [Flag of Manchukuo.svg](https://commons.wikimedia.org/wiki/File:Flag_of_Manchukuo.svg) |
| honduras.svg | Honduras | [Flag of Honduras (1949–2022, 2026–present).svg](https://commons.wikimedia.org/wiki/File:Flag_of_Honduras_(1949–2022,_2026–present).svg) |

Two more former countries need no file, because their last flag is identical
to a current one that flagcdn.com has: Czechoslovakia (today's Czech flag) and
North Vietnam (today's Vietnamese flag).
